# Media Stream Bridge

Firefox で閲覧中のページが利用するストリーム配信を検出し、ローカルへ保存するためのツール。

ブラウザ上でストリームを探す手間と、配信形式に応じた保存操作を簡潔にする。ストリームの検出と選択を Firefox 拡張が担い、保存処理はローカルの ffmpeg へ委譲する構成を検討している。

## ステータス

構想段階。現在は目的と対象範囲を整理しており、実装はまだ存在しない。

## 目的

1. 現在のタブで利用されているストリームを検出する
2. 配信形式や画質候補を一覧表示する
3. 保存するストリームを選択する
4. 保存の進捗と結果を確認する

## 対象範囲

当面は、Firefox で再生される、DRM のない HLS VOD（`.m3u8`）を対象とする。

将来的な候補として、MPEG-DASH とライブストリームを検討する。直接配信される MP4 や WebM など、ブラウザだけで保存できる単一ファイルは対象にしない。

## 構成案

```text
動画ページ
    |
    v
Firefox 拡張
    |
    v
ローカル処理
    |
    v
ffmpeg --> ファイル保存
```

構成や技術選択は現時点の仮説であり、実装と検証で得られた事実に応じて決定する。
