# 初期版ロードマップ

## 位置付け

この文書は、Media Stream Bridge の初期版を完成させるまでの到達点と現在地を管理する。プロダクトの目的と対象範囲は [`README.md`](../README.md)、コンポーネント境界は [`design/architecture.md`](design/architecture.md) を正本とし、ここでは複写しない。

ロードマップは現時点の仮説であり、実装と検証で得た事実に応じて順序や到達点を見直す。初期版の完成後は、継続して扱う項目を Issue などへ移し、この文書を現在の計画に合わせて縮小または廃止する。

## 管理方針

- 利用者が確認できる成果を一つの段階とし、ファイル、クラス、関数単位のタスクは置かない。
- 実装方法や細かな作業順は固定せず、コード、契約、テスト、コミットで具体化する。
- 状態は `未着手`、`進行中`、`完了`、`保留` のいずれかで表す。
- 完了はコードの存在ではなく、各段階に記載した結果を検証できた時点とする。
- 新しい要望を無条件に追加せず、初期版の目的に必要かを確認してから到達点を変更する。

## 現在地

HLSストリーム候補をタブごとに検出し、Popupで表示・選択する実装と自動テストまで完了している。Firefox上で実際のページを使った確認が残っているため、現在は「1. ストリームを検出・選択できる」を進行中とする。

ローカルファイルへの保存、Native Host、保存設定、ジョブ管理は未実装である。

## 到達点

### 1. ストリームを検出・選択できる

**状態: 進行中**

閲覧中のタブが利用する対象範囲内のHLSストリームを検出し、候補が一つなら自動選択、複数なら利用者が選択できる。

完了は、Firefox上の実際のページで候補を選択でき、通常利用を妨げる不要な候補がある場合には初期版に必要な絞り込みを反映できたことで確認する。

### 2. 選択したストリームを保存できる

**状態: 未着手**

選択したストリームをFirefox拡張からNative Hostへ安全に渡し、固定した初期設定でffmpegを起動して、一つのローカルファイルとして保存できる。

完了は、WebExtensionとローカル環境の境界で入力が検証され、対象範囲内のHLS VODを実際に保存して再生できたことで確認する。

### 3. 保存処理の状態を扱える

**状態: 未着手**

保存の進捗、完了、失敗をFirefox上で確認でき、利用者が保存をキャンセルできる。Popupやタブを閉じた場合を含むジョブの生存期間は基本設計に従う。

完了は、正常終了だけでなく失敗とキャンセルでも、結果が利用者へ伝わり、管理されないffmpegプロセスが残らないことで確認する。

### 4. 保存方法を選べる

**状態: 未着手**

デフォルト設定ですぐ保存する操作と、ファイル名、保存先、画質などを今回だけ確認または変更して保存する操作を使い分けられる。

完了は、マスタープレイリストを含む対象ストリームについて、選択した設定が保存結果へ反映され、無効な値や同名ファイルを安全に扱えることで確認する。

### 5. 日常利用できる初期版にする

**状態: 未着手**

macOS上でFirefox拡張、Native Host、ffmpegを利用可能な状態に準備し、対象範囲と既知の制約を理解した上で繰り返し利用できる。

完了は、導入手順を新しい環境で再現し、検出から保存結果の確認までの主要な操作と代表的な失敗を一通り検証できたことで確認する。

## 現在の焦点

まず到達点1をFirefox上で検証する。結果から候補の絞り込みに追加対応が必要かを判断し、完了後に到達点2の最小の保存経路へ進む。
