# 初期版ロードマップ

初期版の到達点は完了した。今後の機能追加や優先順位は、この文書ではなく Issue など利用中の課題管理で扱う。

## 完了した到達点

1. HLS ストリームを検出し、候補を選択できる
2. 選択したストリームを Native Host と ffmpeg を通じて保存できる
3. 保存中、完了、失敗、キャンセルの状態を扱える
4. 既定の保存と、ファイル名・保存先を指定した保存を使い分けられる
5. macOS、Firefox、Native Host、ffmpeg を前提とした初期版の利用手順を整備した

現在の機能、利用方法、対象範囲は [README](../README.md) を参照する。
