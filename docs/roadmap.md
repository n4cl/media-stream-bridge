# 初期版ロードマップ

## 位置付け

この文書は、Media Stream Bridge の初期版で何をどの順で利用可能にし、各到達点を何で確認するかを示す。プロダクトの目的と対象範囲は [`README.md`](../README.md)、コンポーネント境界は [`design/architecture.md`](design/architecture.md) を正本とし、ここでは複写しない。

ロードマップは現時点の仮説であり、実装と検証で得た事実に応じて順序や到達点を見直す。初期版の完成後は、継続して扱う項目を Issue などへ移し、この文書を現在の計画に合わせて縮小または廃止する。

## 現在の到達点

到達点1から3は到達済みである。到達点4以降は後続の到達点とする。

## 到達点

### 1. ストリームを検出・選択できる

**利用者成果:**
閲覧中のタブが利用する対象範囲内のHLSストリームを検出し、候補が一つなら自動選択、複数なら利用者が選択できる。

**到達の確認:**
Firefox上の実際のページで候補を選択でき、通常利用を妨げる不要な候補がある場合には初期版に必要な絞り込みを反映できる。

### 2. 選択したストリームを保存できる

**利用者成果:**
選択したストリームをFirefox拡張からNative Hostへ安全に渡し、固定した初期設定でffmpegを起動して、一つのローカルファイルとして保存できる。

**到達の確認:**
WebExtensionとローカル環境の境界で入力が検証され、対象範囲内のHLS VODを実際に保存して再生できる。

### 3. 保存処理の状態を扱える

**利用者成果:**
保存中であること、完了、失敗、キャンセルをFirefox上で確認できる。Popupやタブを閉じた場合を含むジョブの生存期間は基本設計に従う。

**到達の確認:**
正常終了だけでなく代表的な失敗とキャンセルでも結果が利用者へ伝わり、管理されないffmpegプロセスが残らないことをFirefox上で確認できる。

### 4. 保存方法を選べる

**利用者成果:**
デフォルト設定ですぐ保存する操作と、ファイル名、保存先、画質などを今回だけ確認または変更して保存する操作を使い分けられる。

**到達の確認:**
マスタープレイリストを含む対象ストリームについて、選択した設定が保存結果へ反映され、無効な値や同名ファイルを安全に扱える。

### 5. 日常利用できる初期版にする

**利用者成果:**
macOS上でFirefox拡張、Native Host、ffmpegを利用可能な状態に準備し、対象範囲と既知の制約を理解した上で繰り返し利用できる。

**到達の確認:**
導入手順を新しい環境で再現し、検出から保存結果の確認までの主要な操作と代表的な失敗を一通り検証できる。
